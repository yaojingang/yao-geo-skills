# Yao GEOFlow Template

`yao-geoflow-template` is now a legacy compatibility entrypoint. Use it only for explicit old GEOFlow PHP template-package questions, historical `tokens.json` / `mapping.json` / `manifest.json` outputs, or the old `index.php`, `article.php`, `category.php`, `archive.php`, and `includes/*.php` contract. Current Laravel Blade themes, reference-site mapping, homepage modules, `lead_form`, and channel frontend adaptation belong in `yao-geoflow-design`.

## What It Is For

- explaining old PHP template-package contracts
- reviewing historical mapping, tokens, and manifest files
- identifying legacy template outputs
- writing migration notes for `yao-geoflow-design`

## What It Is Not For

- new Laravel Blade theme work
- reference-site cloning or homepage module design
- lead forms, channel frontend capability checks, or target-package mapping
- direct deployment of legacy PHP templates
- backend refactors, SEO contract changes, or route rewrites
