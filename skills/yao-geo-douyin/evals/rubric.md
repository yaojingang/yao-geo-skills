# 输出审核标准

每项按1–5分审核：1为缺失或失实，3为部分符合，5为完整且有可核对证据。截图、输入和路径任一失实时，完整采集交付失败。

| 维度 | 5分条件 |
| --- | --- |
| 来源与真实性 | 建议来自当前抖音下拉，真实截图包含正确输入和采集行；合成样例明确标注。 |
| 时效与范围 | 记录实际URL与时间，说明批次、限额、截断和未完成范围。 |
| 路径与原文 | 保留原文、大小写、标点、位置及两层来源；共享查询复用且路径完整。 |
| 行业评分 | 行业和转化目标一致；采购、信息、经营、求职等意图区分合理，同词同分并附理由。 |
| 交付与边界 | 五张表、JSON和可用截图链接齐备；遇到验证停止，不承诺免风控或成交概率。 |

真实网页审核以截图和采集JSON为证据；离线校验只证明相应数据契约，独立模型审核未运行时标注missing evidence。
