# 失败与恢复案例

- 中文漏输、粘贴内容不一致：核对完整值，排除错误列表；在同一授权输入框内有限重试。
- 下拉仍为上一词或处于加载状态：观察新列表并核对稳定性，无法确认记error。
- 正确输入但无建议：确认聚焦、等待结束和无阻断，保存空状态截图及empty_confirmation。
- 登录、验证码或频率限制：记blocked，保存检查点并停止整个批次，用户处理后恢复。
- 用户切换窗口或正在操作：暂停全局按键，重新确认目标窗口和输入框。
- 不同查询共用截图、格式与扩展名不符、危险路径或非法Excel文本：导出拒绝错误数据，已有工作簿保持完整。
- 已达查询上限或下拉超出可见范围：保留pending或list_truncated，说明实际完成范围。

合成测试涵盖路径、共享查询、自身词、输入核对、空结果、受阻及导出边界；实际平台验证方式由当时页面决定。
