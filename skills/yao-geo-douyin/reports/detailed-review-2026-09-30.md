## 已确认并修复

| 问题或遗漏 | 修复与验证 |
|---|---|
| “装修家居”画像名称无法用于导出 | 补齐行业别名；七个内置画像的名称与ID均可往返导出。 |
| 法律定义、资料词因包含“律师”获得高分 | 先识别概念、下载、模板、案例、职业考试和影视信息，保留明确委托与报价意图。 |
| 模板排除压低明确委托；同义词序产生错误 | 文书动作、律师主体及委托/费用信号分别核对。例如“找律师审核合同模板多少钱”和“审核合同模板找律师多少钱”均为10分。 |
| 教育、留学面试辅导误判为招聘 | 区分求职面试和付费培训、申请辅导，复核前后词序；招聘词仍降分。 |
| GEO采购获客服务误判为服务方找客户 | 收窄服务方获客规则，保留明确服务商报价与公司咨询。 |
| 电商售后、店铺经营和商品用途被采购信号覆盖 | 退换货、维修、保修与售后优先；开店、注册、运营降分；面试服装购买保留采购判断。 |
| 自定义正则编译可绕过匹配超时 | 编译前限制有限重复展开，覆盖省略下界与嵌套形式；用实际引擎预编译并缓存。匹配阶段仍限定50毫秒。 |
| POSIX文件名可形成Windows网络/驱动器链接 | 拒绝反斜线、冒号、控制字符、危险分段及完整设备保留名，包含COM/LPT上标数字和CONIN$/CONOUT$。 |
| 中文、空格、#及%文件名的链接未编码 | 单元格保留实际相对路径，超链接使用URI编码；解析链接后逐一核对包内目标存在。 |
| `./` 截图引用与查询图片列表不一致 | 两处使用同一规范化函数，再比较归属，多图引用可正常导出。 |
| JSON文件符号链接造成截图与输出目录错位 | 统一以传入JSON路径的访问目录作为相对路径基准，输出须在同一目录。 |
| 公式防护在原词前添加额外字符 | 用Excel文本类型和文本标记存储，原词保持完整，工作表中不生成公式节点。 |
| XML非法字符能生成无法打开的Excel | 入表前校验所有文本，明确拒绝非法控制字符、孤立代理字符及U+FFFE/U+FFFF。 |
| 根词汇总等派生字段被静默截断 | 所有入表文本统一限制32767字符，超长聚合明确报错，已有Excel保持完整。 |
| 同图的大小写或硬链接别名绕过跨查询复用检查 | 按实际文件设备号/文件号校验归属，两个不同检索无法共用同一文件的别名。 |

浏览器规程同步增加目标标签页与焦点核对、用户操作时暂停输入、连接超时后检查实际状态，以及30秒观察上限和最多2次重输。观察超时作为错误保存，不能单独据此认定空结果。

评分是当前行业转化目标下的规则估计。复核补充了语义正反对照与词序变体；新行业和实际采集词仍需按画像抽查，不能把评分解释为成交概率。
