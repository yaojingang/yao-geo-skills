# 浏览器采集规程

1. 优先接续用户已打开的 `xiaohongshu.com/explore` 标签页。保持用户现有浏览器窗口尺寸。使用页面顶部搜索框，不依赖固定坐标；页面结构变化时通过可见标签重新定位。
2. 清空旧输入，输入完整检索词。先核对搜索框文字，再确认下拉列表已从前一个检索词更新；在两次观察中列表内容稳定后截图。若列表暂时仍是旧词的结果，继续等待本次更新，不记录旧列表。建议词列表消失时重新聚焦输入框。
3. 截图包括输入框及整个下拉框；分屏时追加截图。按视觉自上而下编号，保留词条原文、空格及标点。仅采集当前词触发的建议，忽略历史/热搜/广告。
4. 每次记录实际页面 URL 与时间。两层联想词采集无需提交搜索；若页面布局只在搜索结果页显示顶部输入框，可进入结果页后重新聚焦输入框，但不得将结果页推荐词当成下拉词。
5. 每完成一个检索词就保存 JSON 检查点。第二层查询按第一层建议词的首次出现顺序去重。多个词根指向同一第一层词时只查询一次，导出时恢复全部路径。
6. 遇到登录、验证码、频率限制，停止触发该限制的连续操作，记录 `blocked` 并等待用户处理。延时后重试只用于普通加载；不绕过平台限制。
7. 导出前检查每个 `ok` 和 `empty` 项的截图文件存在，词条位置与截图一致。对高分词再核对原文，尤其排除机构招聘、备案、创业、办公装修、运营和娱乐内容等偏离转化目标的意图。
