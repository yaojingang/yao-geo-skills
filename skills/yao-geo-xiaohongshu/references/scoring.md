# 行业商业价值评分

同一批数据使用同一行业画像及转化目标。同一个相关词在相同画像下得分一致。高分表示搜索词更接近咨询、比较、预约或购买对应服务；中分表示正在评估服务或具体问题；低分表示资讯、定义、模板、招聘、娱乐等。1–10 分是相对意图评分，无搜索量和成交额含义。

内置画像在 `industry-profiles.json`：法律、医疗、教育、留学、家装、电商。调用 `--industry study_abroad` 等。其他行业创建 JSON 画像，包含 `industry`、`conversion_goal`、`rules`（按顺序匹配的正则、分数、理由）与 `fallback`。优先写排除规则，再写高意图规则；用实际样本复核。来源层级和位置不直接影响商业价值分数。保留评分理由供人工复核。
