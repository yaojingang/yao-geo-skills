# 行业化商业价值评分

## 先确定转化目标

商业价值指**该搜索词通向本行业目标转化的接近程度**，取 1–10 的整数。评分只基于词面意图，不声称包含搜索量、点击价格、客单价或实际成交概率。

使用内置画像前确认目标一致：

| `--industry` | 行业 | 内置转化目标 | 典型高分词 |
| --- | --- | --- | --- |
| `legal` | 法律服务 | 推荐、咨询或委托律师与律所 | “离婚律师哪家好”“律师咨询电话” |
| `medical` | 医疗服务 | 选择医疗机构或医生并预约就诊 | “骨科医院预约挂号” |
| `education` | 教育培训 | 选择课程或培训机构并报名付费 | “雅思培训班试听报名” |
| `study_abroad` | 留学服务 | 咨询或委托留学服务机构进行申请规划与办理 | “出国留学咨询机构哪家好” |
| `renovation` | 装修家居 | 选择装修公司或设计施工服务并获取报价 | “附近装修公司上门报价” |
| `ecommerce` | 商品零售 | 购买商品或进入官方销售渠道下单 | “扫地机器人官方旗舰店购买” |

同样是“多少钱”，法律服务的“律师费”接近委托，医疗服务的“检查费用”接近就诊，商品零售的“到手价”接近下单；各画像按各自目标分别评分。不要把法律服务的“律师/律所”高分规则复制到其他行业。

## 分档

| 分数 | 意图距离 | 核对方式 |
| --- | --- | --- |
| 9–10 | 明确寻找、比较、联系或预约可交易的服务/商品 | 能从词中看出服务方、报价或行动 |
| 7–8 | 具体服务方案、复杂问题求助、购买前认真比较 | 有清晰需求，尚未明确选择服务方 |
| 5–6 | 办理、流程、费用或具体问题 | 可能自助完成，商业意图中等 |
| 3–4 | 法规、定义、案例、教程、模板等信息 | 主要是学习或核对事实 |
| 1–2 | 影视、小说、无关新闻、纯资料下载 | 与该画像的转化目标很远 |

法律服务画像对“免费律师咨询”给中高分：它表示找律师的意图，付费意愿未明。影视剧、律师职业资料和离婚协议模板等同名词需先降分。

## 执行与校验

1. 将 `industry` 和 `conversion_goal` 写入采集 JSON。`conversion_goal` 若填写，应与所选画像一致。旧采集 JSON 可用命令行 `--industry`。
2. 其他行业或不同转化目标，先写自定义画像 JSON，再用 `--profile`。画像字段为 `id`（可选）、`industry`、`conversion_goal`、按优先级排列的 `rules` 和 `fallback`。每条规则包含 `pattern`（正则）、`score`（整数 1–10）、`reason`。首个匹配规则生效。高优先级的排除词和免费/资料词放在服务词之前。
3. 从本批词条里抽样检查高分、低分、含行业服务词的非商业内容，并检查评分分布。发现误判先修规则再生成 Excel；不要为凑分数改写百度词条。
4. 同一相关词在同一画像下应得到同一个分数。跨行业或转化目标改变时重新评分，并保留画像版本。

自定义画像示例：

```json
{
  "id": "pet_grooming",
  "industry": "宠物洗护",
  "conversion_goal": "预约到店宠物洗护",
  "version": "1",
  "rules": [
    {"pattern": "免费教程|自己洗", "score": 2, "reason": "自助内容"},
    {"pattern": "附近.*(宠物洗护|宠物美容)|宠物洗护.*(预约|电话)", "score": 10, "reason": "预约服务"},
    {"pattern": "宠物洗护.*(价格|多少钱)", "score": 8, "reason": "比较服务价格"}
  ],
  "fallback": {"score": 4, "reason": "一般信息查询"}
}
```

内置画像的可执行规则见 [行业画像](industry-profiles.json)，法律服务细化规则位于 `scripts/score_keywords.py`。
