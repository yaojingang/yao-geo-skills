# 输出风险清单

| 风险 | 检查方式 |
| --- | --- |
| 把侧栏词或“大家还在搜”算入页尾词 | 截图应显示主结果区页尾标题与分页栏；逐条与截图核对 |
| 截图与关键词、来源错配 | 文件编号、输入框或页尾标题、JSON 路径逐词核对 |
| 一类词跨多张截图时遗漏后续证据 | 核对“截图索引”是否逐张列出并可打开 |
| 下拉词高亮片段导致漏字或多余空格 | 同时查看可见文本与截图，校验完整词条 |
| 页面缺失时补造词条 | `empty`、`blocked`、`error` 明示，词条留空 |
| 去重丢失来源 | Excel 同一行保留两种来源与各自顺序 |
| Excel 文本被解释成公式 | 写入时强制词条单元格为文本 |
| 结果随时间或地区改变 | 保存采集时间、实际 URL 和当时截图 |
| 已采集页尾词却没有结果页 URL | 生成 Excel 前校验 `search_url` 必填且属于百度域名 |
| 用同一评分逻辑处理所有行业 | 运行前确认行业和目标转化，选对应画像；不同目标使用自定义画像 |
| “律师”影视词、免费资料或非购买查询被评为高价值 | 抽查高低分样本，排除同名娱乐和低商业意图词 |
| 不同目标词下同一相关词被打出不同分数 | 同一画像对词面评分，检查重复词的一致性 |
| 将评分误当作搜索量、竞价或成交概率 | Excel 只标“商业价值评分”，交付说明其为搜索意图判断 |
