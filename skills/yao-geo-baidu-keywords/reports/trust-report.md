# 开源信任检查

检查日期：2026-09-28。范围：本 skill 的入口、脚本、依赖、公开留学示例和仓库导航。

| 项目 | 结论 |
|---|---|
| 浏览器权限 | 仅要求读取百度普通搜索页面并保存本地截图；遇到验证码交给用户。 |
| 网络边界 | 采集规程要求真实浏览器交互；工作簿脚本不发起网络请求。 |
| 文件边界 | 工作簿脚本只接受采集目录内的截图路径，并校验图片扩展名与文件存在性。 |
| 依赖 | `openpyxl>=3.1,<4`；无私有 SDK、凭据或远程脚本执行。 |
| 公开示例 | `file-backed fixture`：用户提供的留学 Excel 经公开化处理；5 个目标词、98 条相关词和评分保留，浏览器个人界面截图不公开，截图超链接移除，结果页 URL 规范化。 |
| 私密信息 | 已检查技能文本、脚本与公开 Excel，未发现本机绝对路径、账号凭据、个人邮箱或原始浏览器截图。 |

**output contract**：完整运行生成采集 JSON、真实截图及带评分的 Excel；公开示例用于展示表格结构与评分结果。

**rollback boundary**：该 skill 的采集操作只读外部页面，生成文件留在用户指定的本地目录；可删除本次输出并重跑。

**missing evidence**：仓库持续集成环境没有登录中的真实浏览器，无法自动重放百度页面及截图过程。页面结构随时间变化，运行时仍须检查每张截图和词条。
